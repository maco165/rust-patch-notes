상자의 내용물은 언제 정해질까?

Barrel, Military Crate, Locked Crate의 내용물이 언제, 어떻게 정해지는지 서버 코드로 확인했습니다. 내용물은 상자가 스폰될 때 정해지며, 여는 사람이나 시각으로는 바뀌지 않습니다.

결론

내용물은 상자가 스폰될 때 정해집니다

열 때가 아닙니다. 상자가 서버에 나타나는 순간 추첨이 끝나고, 실제 아이템이 상자 안에 들어갑니다. 여는 사람, 시각, 장소, 근처의 플레이어는 추첨에 쓰이지 않습니다.

  • 0회열 때 이루어지는 추첨
  • 60~120분모뉴먼트의 Barrel, Crate, Military Crate의 내용물이 갱신되는 간격
  • 52%Elite Crate에서 총이 1정 이상 나올 확률

2026-11-07 버전 서버의 코드와 데이터를 읽은 결과입니다.

상자의 일생

  1. 스폰순식간여기서 추첨이 끝나고 내용물이 들어간다
  2. 놓여 있음60~120분내용물은 바뀌지 않는다
  3. 갱신순식간내용물을 전부 지우고 다시 추첨한다
  4. 비워짐—상자가 사라지고, 나중에 새 상자가 스폰된다
  • 여는 처리는 처음 연 사람을 기록할 뿐, 추첨은 하지 않습니다.
  • 재시작 후 세이브에서 복원되는 상자는 추첨 없이 이전 내용물을 되돌립니다.

추첨에 쓰는 것, 쓰지 않는 것

쓰는 것

  • 상자 종류별 설정 (슬롯 목록, Scrap 개수)
  • 추첨 테이블 (가중치와 개수)
  • 난수
  • 서버의 시대 설정

쓰지 않는 것

  • 여는 사람
  • 시각, 와이프 후 경과 일수
  • 상자의 위치
  • 근처의 플레이어, 서버 인원
  • 이전에 나온 내용물
  • 여는 방법, 부수는 방법

내용물이 정해지는 방식

추첨은 2단계로 되어 있습니다. 상자마다의 "슬롯"과, 슬롯이 뽑는 "테이블"입니다.

상자가 스폰될 때:
  상자의 슬롯을 위에서부터 차례로 본다
    슬롯마다 정해진 횟수만큼:
      0 이상 1 이하의 난수가 슬롯의 확률 이하이면, 그 슬롯의 테이블을 1번 뽑는다
  Scrap을 상자마다 정해진 개수만큼 넣는다

테이블을 1번 뽑는다:
  하위 테이블이 나열되어 있으면, 가중치에 비례해 하나를 골라 그 테이블을 뽑는다 (잎에 닿을 때까지 반복)
  아이템이 나열되어 있으면 (잎), 나열된 아이템을 전부 넣는다

슬롯: Military Crate의 예

Military Crate (crate_normal)에는 슬롯이 8개 있습니다. 슬롯은 서로 관계없이 뽑힙니다.

테이블: 가중치로 하나를 고른다

테이블 (LootSpawn)은 트리 구조입니다. Military Crate의 "부품 테이블"은 6개의 하위 테이블을 가중치로 고릅니다. 가중치의 합계는 600입니다.

  1. SMG Body20%
  2. Tech Trash17%
  3. Metal Pipe17%
  4. High Quality Metal17%
  5. 터렛 부품17%
  6. Rifle Body13%

"터렛 부품"은 다시 하위 테이블로, Targeting Computer (가중치 55), CCTV Camera (45), Auto Turret (5) 중 하나를 고릅니다. 부품 테이블에서 Auto Turret이 나올 확률은 100/600 × 5/105 = 0.79%입니다.

잎에 닿으면 나열된 아이템이 전부 들어갑니다 ("Uzi와 탄약"이라면 Uzi와 Pistol Bullet 15발).

호출하는 난수

추첨이 쓰는 난수는 Unity에 기본으로 있는 UnityEngine.Random.Range뿐입니다.

정하는 것호출하는 메서드성질
슬롯이 당첨되는지UnityEngine.Random.Range(0f, 1f)0 이상 1 이하의 실수. 슬롯의 확률 이하이면 당첨
하위 테이블 중 어느 것UnityEngine.Random.Range(0, 가중치 합계)정수 버전. 최솟값을 포함하고 최댓값을 포함하지 않는다
개수UnityEngine.Random.Range(최소, 최대)실수 버전. 결과의 소수점을 버려서 쓴다
무기의 내구도UnityEngine.Random.Range(하한, 상한)실수 버전. 최대 내구도에 곱한다
다음 갱신까지의 초UnityEngine.Random.Range(최소, 최대)실수 버전

난수의 상태는 서버 전체에서 공유되므로 밖에서는 읽을 수 없습니다.

의외였던 4가지

개수의 "최대"는 나오지 않는다

개수는 "최소~최대의 실수를 버림"이므로 최대는 거의 나오지 않습니다.

블루프린트로 나오는지는 아이템마다 정해져 있습니다. 블루프린트로 나오는 것은 12종 (Barbeque, Wheelbarrow Piano, Minicopter 등)뿐입니다.

같은 것의 재추첨은 없다

같은 것이 2번 당첨되면 그대로 2개가 들어갑니다. 상자의 칸을 넘친 것은 사라집니다 (Bradley Crate에서 6%).

횟수가 0인 슬롯이 있다

Crate의 "터렛 부품 4%" 슬롯은 횟수가 0이라 당첨되지 않습니다.

똑같이 움직이는 프로그램

직접 처음부터 쓴, 똑같이 움직이는 프로그램입니다 (게임 코드는 베끼지 않았습니다). 예시는 Military Crate의 부품 테이블과 작은 슬롯 몇 개뿐입니다.

def roll_amount(amount, maximum, rng):
    """최소부터 최대까지의 실수를 뽑아 소수점을 버린다. 최대 그 자체는 나오지 않는다"""
    if maximum > 0 and maximum > amount:
        return max(1, int(rng.uniform(amount, maximum)))
    return max(1, int(amount))

def spawn(table, rng, box):
    """테이블을 1번 뽑는다. 하위 테이블이 있으면 가중치로 하나를 고르고, 잎에 닿으면 전부 넣는다"""
    subs = TABLES.get(table)
    if subs:
        left = sum(weight for weight, _ in subs)
        pick = rng.randrange(left)
        for weight, name in subs:
            left -= weight
            if pick >= left:
                spawn(name, rng, box)
                return
    for item, amount, maximum in ITEMS.get(table, []):
        box[item] += roll_amount(amount, maximum, rng)

def fill(rng):
    """상자 1개. 여는 사람도 시각도 장소도 들어오지 않는다. 테이블과 난수뿐"""
    box = collections.Counter()
    for table, tries, chance in SLOTS:
        for _ in range(tries):
            if rng.random() <= chance:
                spawn(table, rng, box)
    box["scrap"] += SCRAP
    return box

자주 듣는 이야기를 확인한다

"여는 사람에 따라 내용물이 달라진다"

달라지지 않는다내용물은 상자가 스폰될 때 이미 들어 있고, 여는 처리는 추첨을 하지 않습니다. 누가 열어도 같은 상자에서는 같은 것이 나옵니다.

"사람이 적은 시간대에는 좋은 것이 나온다"

달라지지 않는다추첨은 시각도 서버 인원도 쓰지 않습니다. 인원이 관계하는 것은 비워진 상자가 다시 스폰될 때까지의 속도뿐입니다.

"Locked Crate는 해킹이 끝났을 때 내용물이 정해진다"

놓였을 때 정해져 있다Locked Crate도 나타났을 때 추첨을 마칩니다. 15분은 열 수 있게 될 때까지의 대기 시간입니다.

"Barrel은 부수는 방법에 따라 떨어지는 것이 달라진다"

달라지지 않는다Barrel의 내용물도 스폰될 때 정해져 있고, 부수면 들어 있던 것이 그대로 떨어집니다. Scrap이 늘어나는 효과의 추가분만 부술 때 더해집니다.

"조금만 남겨 두면 그 상자는 계속 그대로다"

시간이 되면 갱신된다모뉴먼트의 상자는 남겨 둬도 사라지지 않지만, 60~120분의 갱신 때 남은 것이 사라지고 새 내용물이 됩니다. 길가의 잡동사니 더미 상자는 1개라도 가져가면 사람이 떠나고 90초 뒤 더미째 사라집니다. 비운 상자가 몇 분 만에 다시 스폰되는지는 아직 조사하지 않았습니다.

"좋은 것이 나온 상자 자리는 다음에도 좋은 것이 나온다"

관계없다추첨은 상자의 위치도 이전에 나온 내용물도 쓰지 않습니다. 매번 같은 테이블에서 다시 뽑을 뿐입니다.

"Military Crate를 계속 돌면 언젠가 Timed Explosive Charge (C4)가 나온다"

나오지 않는다Military Crate의 테이블에는 Timed Explosive Charge (C4)가 없습니다. 상자에서 노린다면 Bradley Crate (36%), Supply Drop (27%), Heli Crate (26%), Locked Crate (9.6%), Elite Crate (1.9%)입니다.

알 수 없는 것

  • 갱신 시간이 무한대인 상자. Elite Crate와 Locked Crate는 갱신 시간에 무한대가 들어 있습니다. 타이머는 "예약 시각이 되면 움직이는" 구조이므로, 무한대라면 움직이지 않는다고 읽힙니다. 다만 무한대를 받은 Unity의 난수가 무엇을 돌려주는지는 Unity 본체 안의 일이라 확인하지 않았습니다.
  • 재스폰 간격과 장소. 비워진 상자가 몇 분 만에 다시 스폰되는지, 어느 장소에 어떤 상자가 스폰되는지는 모뉴먼트 데이터를 읽지 않았으므로 알 수 없습니다.
  • 게임 모드의 보너스. 추첨 가중치에는 게임 모드별 보너스를 더하는 구조가 있습니다. 일반 모드는 보너스가 없고, 이 글의 숫자는 그 경우입니다. 서버의 시대 설정은 기본값 (제한 없음)으로 가정했습니다. Hardcore나 Primitive 같은 모드에서는 달라집니다.
  • 상자 외형과의 대응. 프리팹 이름과 게임 안 상자의 외형, 이름의 대응은 프리팹 이름으로 추정한 것입니다.
  • 이 글의 대상. 2026-11-07 버전입니다. 테이블의 가중치는 업데이트로 자주 바뀝니다.
  • 2020년 Supply Drop의 횟수. "8번"은 지금의 Supply Drop 상자에 남아 있는 옛 설정 (maxDefinitionsToSpawn 8)입니다. 슬롯이 없는 상자가 이 횟수만큼 테이블을 뽑는 처리는 지금도 남아 있지만, 2020년의 값이 8이었는지는 확인하지 않았습니다.
  • 2020년의 코드. 옛 서버 버전은 구할 수 없으므로 2020-11과 2021-08은 클라이언트의 테이블만 읽었고, 블루프린트가 되는지는 지금과 같은 아이템 플래그 (spawnAsBlueprint)로 정해진다고 보고 계산했습니다. 2021-08과의 차이에는 Tech Tree Update 이외의 업데이트에서 바뀐 것도 들어 있습니다.
  • 2020년 이전. 연표에서 그보다 앞선 업데이트는 공식 변경 사항의 글만으로 썼습니다.

조사 방법

서버의 코드와 상자 설정 105개, 추첨 테이블 1,327개를 읽었습니다 (서버는 실행하지 않았습니다). 확률은 테이블에서 계산했고, 직접 만든 프로그램의 10만 상자와 0.5포인트 이내로 맞는 것을 확인했습니다 ("총 1정 이상"과 Bradley는 시뮬레이션 값). 옛 버전의 테이블은 scripts/dump_loot_spawns.py로 읽었습니다. 게임 안에서 상자를 열어 센 결과가 아닙니다.
