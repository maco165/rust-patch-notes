箱の中身はいつ決まるのか

樽や軍用箱、ロックされた箱の中身が、いつ、どう決まるかをサーバーの処理から確かめました。中身は箱が湧いた時に決まり、開ける人や時刻では変わりません。

結論

中身は、箱が湧いた時に決まります

開けた時ではありません。箱がサーバーに現れた瞬間に抽選が終わり、実物のアイテムが箱の中に入ります。開ける人、時刻、場所、近くにいるプレイヤーは、抽選に使われません。

  • 0 回開けた時に行われる抽選
  • 60〜120 分モニュメントの樽・木箱・軍用箱の中身が入れ替わる間隔
  • 52%エリート箱から銃が 1 丁以上出る確率

もう 1 つ、知っておくと得なことがあります。モニュメントに置かれた樽、木箱、軍用箱などは、誰も触っていなくても、時間が来ると中身が丸ごと入れ替わります。道ばたのジャンクの山の箱は別で、入れ替わる前に山ごと消えます (あとの「中身が入れ替わる時間」を見てください)。

この記事は、2026-11-07 の版の PC 版のサーバーの処理とデータを読んだ結果です。箱の名前は日本語で書き、最初に出る所にデータの中の名前 (プレハブ名) を添えます。

箱の一生

  1. 湧く一瞬ここで抽選が終わり、中身が入る
  2. 置かれている60〜120 分中身は変わらない
  3. 入れ替え一瞬中身を全部消して、抽選し直す
  4. 空にされる—箱が消え、後で新しい箱が湧く
  • 湧く: 箱 (LootContainer) がサーバーに現れた時に、抽選をして中身を入れます。サーバーの再起動で箱がセーブから戻る時は、抽選せずにセーブされた中身を戻します。
  • 開ける: 開ける処理がするのは、最初に開けた人の記録と、アイテムに「拾った物」の印を付けることだけです。抽選はしません。
  • 入れ替え: 多くの箱は、湧いた時に「次の入れ替えまでの時間」を乱数で決めます。時間が来ると、中身を全部消して抽選し直し、また次の時間を決めます。開けたかどうかは見ていません。
  • 空にする: 中身を全部取ると、箱は消えます。新しい箱を湧かせるのは別の仕組み (SpawnGroup) で、湧いた箱はまた最初から抽選します。道ばたのジャンクの山の箱は、その場では湧き直しません。

抽選に使うもの、使わないもの

使うもの

  • 箱の種類ごとの設定 (枠の一覧、スクラップの数)
  • 抽選の表 (重みと個数)
  • 乱数
  • サーバーの時代の設定

使わないもの

  • 開ける人
  • 時刻、ワイプからの日数
  • 箱の場所
  • 近くのプレイヤー、サーバーの人数
  • 前に出た中身
  • 開け方、壊し方

サーバーの人数が使われるのは、空にされた箱が湧き直すまでの速さだけです。中身には関わりません。

中身の決め方

抽選は 2 段になっています。箱ごとの「枠」と、枠が引く「表」です。

箱が湧いた時:
  箱の枠を上から順に見る
    枠ごとに、決まった回数だけ:
      0 以上 1 以下の乱数が、枠の確率以下なら、その枠の表を 1 回引く
  スクラップを、箱ごとに決まった数だけ入れる

表を 1 回引く:
  下位の表が並んでいれば、重みに比例して 1 つ選び、その表を引く (葉に着くまで繰り返す)
  アイテムが並んでいれば (葉)、並んでいるアイテムを全部入れる

軍用箱 (crate_normal) には枠が 8 つあります。枠は互いに関係なく引かれます。

表: 重みで 1 つ選ぶ

表 (LootSpawn) は木になっています。軍用箱の「部品の表」は、6 つの下位の表を重みで選びます。重みの合計は 600 です。

  1. SMG ボディ20%
  2. テックトラッシュ17%
  3. 金属パイプ17%
  4. 高品質金属17%
  5. タレットの部品17%
  6. ライフルボディ13%

「タレットの部品」はさらに下位の表で、照準コンピューター (重み 55)、CCTV カメラ (45)、オートタレット (5) から 1 つを選びます。部品の表からオートタレットが出る確率は、100/600 × 5/105 = 0.79% です。

表は全部で 1,327 個あり、そのうち 1,098 個がアイテムの並んだ葉です。葉に着くと、並んでいるアイテムは全部入ります。たとえば「Uzi と弾」の葉は、Uzi 1 丁とピストル弾 15 発を一緒に入れます。

呼んでいる乱数

抽選が使う乱数は、Unity に元からある UnityEngine.Random.Range だけです。

決めること呼んでいるメソッド性質
枠が当たるかUnityEngine.Random.Range(0f, 1f)0 以上 1 以下の実数。枠の確率以下なら当たり
下位の表のどれかUnityEngine.Random.Range(0, 重みの合計)整数の版。最小を含み、最大を含まない
個数UnityEngine.Random.Range(最小, 最大)実数の版。結果の小数を切り捨てて使う
武器の耐久UnityEngine.Random.Range(下限, 上限)実数の版。最大の耐久に掛ける
次の入れ替えまでの秒数UnityEngine.Random.Range(最小, 最大)実数の版

UnityEngine.Random の状態は、サーバー全体で 1 つを共有します。ほかの処理も同じ乱数を使うので、箱が引く時点の状態は外から読めません。

意外だった 4 つのこと

個数の「最大」は出ない

個数は「最小から最大までの実数を取り、小数を切り捨てる」で決まります。切り捨てるので、最大の値になるのは乱数がちょうど最大だった時だけで、起きないと見てかまいません。

アイテム表に書かれた個数実際に出る個数
テックトラッシュ (軍用箱の部品の表)2〜42 か 3 (半々)
金属パイプ (同)5〜6必ず 5
高品質金属 (同)15〜2515〜24
MLRS ロケット弾 (エリート箱の枠)1〜2必ず 1

範囲が書かれているのは一部で、表の中のアイテム 1,239 行のうち 89 行です。残りは決まった数です。

設計図になる「確率」は無い

設計図として出るかどうかは、アイテムごとに決まっています。確率で切り替える処理はありません。設計図として出る設定のアイテムは 12 種 (バーベキュー、ピアノ、ミニコプターなど) だけで、武器や爆発物は実物で出ます。

同じ物の引き直しは無い

同じ物が 2 回当たっても、引き直しません。重ねられる物は 1 つの束になり、武器のように重ねられない物は 2 枠を使います。箱の枠が足りなくなると、入りきらない物は消えます。実際に足りなくなるのはブラッドレーの箱 (bradley_crate) くらいで、試行では 6% の箱で何かが消えました。

回数が 0 の枠がある

木箱 (crate_normal_2) には「タレットの部品、確率 4%」の枠がありますが、引く回数が 0 です。この枠は当たりません。木箱から照準コンピューターと CCTV カメラは出ません。

箱ごとの確率

確率は「1 箱に 1 つ以上入っている確率」です。枠と表の重みから計算し、同じ動きをする自作のプログラムで 10 万箱を試して、差が 0.5 ポイント以内であることを確かめました。ブラッドレーの箱だけは枠があふれるので、試行の値を載せています。箱の見た目とプレハブ名の対応は、名前からの推定です。

放っておくと入れ替わる

  • 15〜30 分食料箱、ゴミの山
  • 30〜60 分石油の樽
  • 60〜120 分樽、木箱、軍用箱、道具箱、水中の箱など

入れ替えの時間は、箱の種類ごとに決まった範囲から乱数で選ばれます。時間が来ると、箱は中身を全部消して、最初と同じ抽選をします。

  • 誰も開けていない箱も入れ替わります。 入れ替えは、開けたかどうかを見ていません。
  • 少しだけ残した箱は、消えずに残ります。 そして次の入れ替えで、残りが消えて新しい中身になります。
  • 道ばたのジャンクの山の箱は、入れ替わる前に消えます。 ジャンクの山 (junkpile_a〜j) は、湧いてから約 30 分たつと、15 m 以内にプレイヤーがいなければ、樽や木箱ごと沈んで消えます。箱から 1 つでも取った後は、15 m 以内に誰もいない状態が 90 秒続いた時点で消えます。山の箱 (樽、木箱、道具箱、車両部品の箱、石油の樽) は、その場では湧き直しません。入れ替えに届くのは、15〜30 分の食料箱だけです。
  • エリート箱、ロックされた箱、補給物資、ヘリとブラッドレーの箱は、入れ替えの時間に無限大が入っていて、入れ替えない設定と読めます。

町と道ばたの箱 (樽、木箱、軍用箱、エリート箱など) から出た武器は、入れた直後に耐久が振り直されます。範囲はアイテムごとに決まっています。

同じ動きをするプログラム

読んで分かった動きを、自分で一から書いたプログラムです。ゲームのコードは写していません。見本として、軍用箱の「部品の表」と小さな枠だけを入れてあります (作業台 Lv2 の品の枠と、作業台アップグレードの枠は省いています)。

def roll_amount(amount, maximum, rng):
    """最小から最大までの実数を取り、小数を切り捨てる。最大そのものは出ない"""
    if maximum > 0 and maximum > amount:
        return max(1, int(rng.uniform(amount, maximum)))
    return max(1, int(amount))

def spawn(table, rng, box):
    """表を 1 回引く。下位の表があれば重みで 1 つ選び、葉に着いたら全部入れる"""
    subs = TABLES.get(table)
    if subs:
        left = sum(weight for weight, _ in subs)
        pick = rng.randrange(left)
        for weight, name in subs:
            left -= weight
            if pick >= left:
                spawn(name, rng, box)
                return
    for item, amount, maximum in ITEMS.get(table, []):
        box[item] += roll_amount(amount, maximum, rng)

def fill(rng):
    """1 箱。開ける人も時刻も場所も入ってこない。表と乱数だけ"""
    box = collections.Counter()
    for table, tries, chance in SLOTS:
        for _ in range(tries):
            if rng.random() <= chance:
                spawn(table, rng, box)
    box["scrap"] += SCRAP
    return box

fill が受け取るのは乱数のもとだけです。開ける人や時刻を渡す場所がありません。

よく聞く話を確かめる

「開ける人によって中身が変わる」

変わらない中身は箱が湧いた時に入っていて、開ける処理は抽選をしません。誰が開けても、同じ箱からは同じ物が出ます。

「人が少ない時間帯は良い物が出る」

変わらない抽選は時刻もサーバーの人数も使いません。人数が関わるのは、空にされた箱が湧き直すまでの速さだけです。

「ロックされた箱は、ハッキングが終わった時に中身が決まる」

置かれた時に決まっているロックされた箱も、現れた時に抽選を済ませます。15 分は、開けられるようになるまでの待ち時間です。

「樽は、壊し方で落ちる物が変わる」

変わらない樽の中身も湧いた時に決まっていて、壊すと入っていた物がそのまま落ちます。スクラップが増える効果の追加分だけは、壊した時に足されます。

「少しだけ残しておくと、その箱はずっとそのまま」

時間が来れば入れ替わるモニュメントの箱は、残しても消えませんが、60〜120 分の入れ替えで、残りが消えて新しい中身になります。道ばたのジャンクの山の箱は、1 つでも取ると、人が離れて 90 秒で山ごと消えます。空にした箱が何分で湧き直すかは、まだ調べていません。

「良い物が出た箱の場所は、次も良い物が出る」

関係ない抽選は箱の場所も、前に出た中身も使いません。毎回、同じ表から引き直すだけです。

「軍用箱を回り続ければ、いつか時限爆弾 (C4) が出る」

出ない軍用箱の表に、時限爆弾 (C4) はありません。箱から狙うなら、ブラッドレーの箱 (36%)、補給物資 (27%)、ヘリの箱 (26%)、ロックされた箱 (9.6%)、エリート箱 (1.9%) です。

分からないこと

  • 入れ替えの時間が無限大の箱。 エリート箱やロックされた箱は、入れ替えの時間に無限大が入っています。タイマーは「予約の時刻が来たら動く」作りなので、無限大なら動かないと読めます。ただし、無限大を渡された Unity の乱数が何を返すかは、Unity 本体の中なので確かめていません。
  • 湧き直しの間隔と場所。 空にされた箱が何分で湧き直すか、どの場所にどの箱が湧くかは、モニュメントのデータを読んでいないので分かりません。
  • ゲームモードの上乗せ。 抽選の重みには、ゲームモードごとの上乗せを足す仕組みがあります。通常のモードは上乗せが無く、この記事の数字はその場合です。サーバーの時代の設定は既定 (制限なし) としています。ハードコアやプリミティブなどのモードでは変わります。
  • 箱の見た目との対応。 プレハブ名と、ゲームの中の箱の見た目・名前の対応は、プレハブ名から推定したものです。
  • この記事の対象。 2026-11-07 の版です。表の重みはアップデートでよく変わります。
  • 昔の表の数字。 「抽選の表の移り変わり」は公式の変更点の文だけから書いています。昔の版の表は読んでいないので、改訂の前後で確率がどれだけ変わったかは分かりません。

調べ方

サーバー本体の処理 (箱と抽選の表のクラスの中間コード) を読み、箱の設定 105 個と抽選の表 1,327 個をデータのファイルから読みました。サーバーは起動していません。枠の確率、重み、個数、スクラップの数、入れ替えの時間、耐久の範囲は、どれも読んだ値です。

「1 箱に 1 つ以上出る確率」は、読んだ値から計算したものです。「銃が 1 丁以上」とブラッドレーの箱の数字、物の種類の平均は、同じ動きをする自作のプログラムで 10 万箱を試した値です (種 1)。計算と試行は、ブラッドレーの箱を除いて 0.5 ポイント以内で合いました。

ゲームの中で実際に箱を開けて数えた結果ではありません。処理とデータがそうなっている、という確認です。
