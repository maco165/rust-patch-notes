箱の中身はいつ決まるのか

樽や軍用箱、ロックされた箱の中身が、いつ、どう決まるかをサーバーの処理から確かめました。中身は箱が湧いた時に決まり、開ける人や時刻では変わりません。

結論

中身は、箱が湧いた時に決まります

開けた時ではありません。箱がサーバーに現れた瞬間に抽選が終わり、実物のアイテムが箱の中に入ります。開ける人、時刻、場所、近くにいるプレイヤーは、抽選に使われません。

  • 0 回開けた時に行われる抽選
  • 60〜120 分モニュメントの樽・木箱・軍用箱の中身が入れ替わる間隔
  • 52%エリート箱から銃が 1 丁以上出る確率

2026-11-07 の版のサーバーの処理とデータを読んだ結果です。

箱の一生

  1. 湧く一瞬ここで抽選が終わり、中身が入る
  2. 置かれている60〜120 分中身は変わらない
  3. 入れ替え一瞬中身を全部消して、抽選し直す
  4. 空にされる—箱が消え、後で新しい箱が湧く
  • 開ける処理は、最初に開けた人を記録するだけで、抽選はしません。
  • 再起動でセーブから戻る箱は、抽選せずに前の中身を戻します。

抽選に使うもの、使わないもの

使うもの

  • 箱の種類ごとの設定 (枠の一覧、スクラップの数)
  • 抽選の表 (重みと個数)
  • 乱数
  • サーバーの時代の設定

使わないもの

  • 開ける人
  • 時刻、ワイプからの日数
  • 箱の場所
  • 近くのプレイヤー、サーバーの人数
  • 前に出た中身
  • 開け方、壊し方

中身の決め方

抽選は 2 段になっています。箱ごとの「枠」と、枠が引く「表」です。

箱が湧いた時:
  箱の枠を上から順に見る
    枠ごとに、決まった回数だけ:
      0 以上 1 以下の乱数が、枠の確率以下なら、その枠の表を 1 回引く
  スクラップを、箱ごとに決まった数だけ入れる

表を 1 回引く:
  下位の表が並んでいれば、重みに比例して 1 つ選び、その表を引く (葉に着くまで繰り返す)
  アイテムが並んでいれば (葉)、並んでいるアイテムを全部入れる

軍用箱 (crate_normal) には枠が 8 つあります。枠は互いに関係なく引かれます。

同じ動きをするプログラム

自分で一から書いた、同じ動きをするプログラムです (ゲームのコードは写していません)。見本は軍用箱の部品の表と小さな枠だけです。

def roll_amount(amount, maximum, rng):
    """最小から最大までの実数を取り、小数を切り捨てる。最大そのものは出ない"""
    if maximum > 0 and maximum > amount:
        return max(1, int(rng.uniform(amount, maximum)))
    return max(1, int(amount))

def spawn(table, rng, box):
    """表を 1 回引く。下位の表があれば重みで 1 つ選び、葉に着いたら全部入れる"""
    subs = TABLES.get(table)
    if subs:
        left = sum(weight for weight, _ in subs)
        pick = rng.randrange(left)
        for weight, name in subs:
            left -= weight
            if pick >= left:
                spawn(name, rng, box)
                return
    for item, amount, maximum in ITEMS.get(table, []):
        box[item] += roll_amount(amount, maximum, rng)

def fill(rng):
    """1 箱。開ける人も時刻も場所も入ってこない。表と乱数だけ"""
    box = collections.Counter()
    for table, tries, chance in SLOTS:
        for _ in range(tries):
            if rng.random() <= chance:
                spawn(table, rng, box)
    box["scrap"] += SCRAP
    return box

よく聞く話を確かめる

「開ける人によって中身が変わる」

変わらない中身は箱が湧いた時に入っていて、開ける処理は抽選をしません。誰が開けても、同じ箱からは同じ物が出ます。

「人が少ない時間帯は良い物が出る」

変わらない抽選は時刻もサーバーの人数も使いません。人数が関わるのは、空にされた箱が湧き直すまでの速さだけです。

「ロックされた箱は、ハッキングが終わった時に中身が決まる」

置かれた時に決まっているロックされた箱も、現れた時に抽選を済ませます。15 分は、開けられるようになるまでの待ち時間です。

「樽は、壊し方で落ちる物が変わる」

変わらない樽の中身も湧いた時に決まっていて、壊すと入っていた物がそのまま落ちます。スクラップが増える効果の追加分だけは、壊した時に足されます。

「少しだけ残しておくと、その箱はずっとそのまま」

時間が来れば入れ替わるモニュメントの箱は、残しても消えませんが、60〜120 分の入れ替えで、残りが消えて新しい中身になります。道ばたのジャンクの山の箱は、1 つでも取ると、人が離れて 90 秒で山ごと消えます。空にした箱が何分で湧き直すかは、まだ調べていません。

「良い物が出た箱の場所は、次も良い物が出る」

関係ない抽選は箱の場所も、前に出た中身も使いません。毎回、同じ表から引き直すだけです。

「軍用箱を回り続ければ、いつか時限爆弾 (C4) が出る」

出ない軍用箱の表に、時限爆弾 (C4) はありません。箱から狙うなら、ブラッドレーの箱 (36%)、補給物資 (27%)、ヘリの箱 (26%)、ロックされた箱 (9.6%)、エリート箱 (1.9%) です。

分からないこと

  • 入れ替えの時間が無限大の箱。 エリート箱やロックされた箱は、入れ替えの時間に無限大が入っています。タイマーは「予約の時刻が来たら動く」作りなので、無限大なら動かないと読めます。ただし、無限大を渡された Unity の乱数が何を返すかは、Unity 本体の中なので確かめていません。
  • 湧き直しの間隔と場所。 空にされた箱が何分で湧き直すか、どの場所にどの箱が湧くかは、モニュメントのデータを読んでいないので分かりません。
  • ゲームモードの上乗せ。 抽選の重みには、ゲームモードごとの上乗せを足す仕組みがあります。通常のモードは上乗せが無く、この記事の数字はその場合です。サーバーの時代の設定は既定 (制限なし) としています。ハードコアやプリミティブなどのモードでは変わります。
  • 箱の見た目との対応。 プレハブ名と、ゲームの中の箱の見た目・名前の対応は、プレハブ名から推定したものです。
  • この記事の対象。 2026-11-07 の版です。表の重みはアップデートでよく変わります。
