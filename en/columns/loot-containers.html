When is a crate's loot decided?

When are the contents of Barrels, Military Crates and Locked Crates decided? The server code says at spawn. The opener and the time change nothing.

Answer

The contents are decided when the crate spawns

Not when it is opened. The roll is finished the moment the crate appears on the server, and real items are placed inside it. The opener, the time, the location and nearby players are not used in the roll.

  • 0 timesRolls made when a crate is opened
  • 60–120 minInterval at which monument Barrels, Crates and Military Crates refresh their contents
  • 52%Chance that an Elite Crate holds at least 1 gun

These are the results of reading the server code and data of the 2026-11-07 version.

The life of a crate

  1. SpawnsAn instantThe roll finishes here and the contents go in
  2. Sits there60–120 minThe contents do not change
  3. RefreshAn instantAll contents are deleted and rolled again
  4. Emptied—The crate disappears, and a new one spawns later
  • The open step only records who opened it first. It does not roll.
  • A crate restored from the save after a restart gets its old contents back without a roll.

What the roll uses, and what it does not

Used

  • Settings for each crate type (the slot list, the amount of Scrap)
  • Loot tables (weights and amounts)
  • Random numbers
  • The server's era setting

Not used

  • Who opens it
  • The time, days since the wipe
  • The crate's location
  • Nearby players, server population
  • What came out before
  • How it is opened or broken

How the contents are decided

The roll has 2 stages: the "slots" of each crate, and the "tables" that the slots draw from.

When a crate spawns:
  Go through the crate's slots from the top
    For each slot, a fixed number of times:
      If a random number from 0 to 1 (inclusive) is at or below the slot's chance, draw from that slot's table once
  Add the crate's fixed amount of Scrap

Draw from a table once:
  If it lists sub-tables, pick 1 in proportion to the weights and draw from that table (repeat until a leaf)
  If it lists items (a leaf), add every listed item

Slots: the Military Crate as an example

The Military Crate (crate_normal) has 8 slots. Each slot is drawn independently of the others.

On top of this, 8 Scrap always go in.

Tables: pick 1 by weight

Tables (LootSpawn) form a tree. The Military Crate's "component table" picks one of 6 sub-tables by weight. The weights add up to 600.

  1. SMG Body20%
  2. Tech Trash17%
  3. Metal Pipe17%
  4. High Quality Metal17%
  5. Turret parts17%
  6. Rifle Body13%

"Turret parts" is itself a sub-table that picks 1 of Targeting Computer (weight 55), CCTV Camera (45) and Auto Turret (5). The chance of an Auto Turret from the component table is 100/600 × 5/105 = 0.79%.

When a leaf is reached, every listed item goes in ("Uzi and ammo" means an Uzi plus 15 Pistol Bullet).

The random numbers it calls

The only random source the roll uses is Unity's built-in UnityEngine.Random.Range.

What it decidesMethod calledBehavior
Whether a slot hitsUnityEngine.Random.Range(0f, 1f)A real number from 0 to 1 (inclusive). A hit if at or below the slot's chance
Which sub-tableUnityEngine.Random.Range(0, total weight)Integer version. Includes the minimum, excludes the maximum
AmountUnityEngine.Random.Range(min, max)Float version. The fraction of the result is dropped
Weapon conditionUnityEngine.Random.Range(lower, upper)Float version. Multiplied by the maximum condition
Seconds until the next refreshUnityEngine.Random.Range(min, max)Float version

The random state is shared across the whole server, so it cannot be read from outside.

4 surprises

The "maximum" amount does not come out

The amount is "a real number from min to max, rounded down", so the maximum almost never comes out.

ItemAmount in the tableAmount that actually comes out
Tech Trash (Military Crate component table)2–42 or 3 (half and half)
Metal Pipe (same)5–6Always 5
High Quality Metal (same)15–2515–24
MLRS Rocket (Elite Crate slot)1–2Always 1

There is no "chance" of a blueprint

Whether something comes out as a blueprint is fixed per item. Only 12 types come out as blueprints (Barbeque, Wheelbarrow Piano, Minicopter, etc.).

No re-roll for duplicates

If the same item hits twice, 2 of it go in. Items that overflow the crate's slots are lost (6% in the Bradley Crate).

Some slots have 0 draws

The Crate's "turret parts 4%" slot has 0 draws, so it never hits.

A program that behaves the same way

This is a program written from scratch that behaves the same way (no game code was copied). The sample covers only the Military Crate component table and a few small slots.

def roll_amount(amount, maximum, rng):
    """Take a real number from min to max and drop the fraction. The max itself never comes out"""
    if maximum > 0 and maximum > amount:
        return max(1, int(rng.uniform(amount, maximum)))
    return max(1, int(amount))

def spawn(table, rng, box):
    """Draw from a table once. If it has sub-tables, pick 1 by weight; at a leaf, add everything"""
    subs = TABLES.get(table)
    if subs:
        left = sum(weight for weight, _ in subs)
        pick = rng.randrange(left)
        for weight, name in subs:
            left -= weight
            if pick >= left:
                spawn(name, rng, box)
                return
    for item, amount, maximum in ITEMS.get(table, []):
        box[item] += roll_amount(amount, maximum, rng)

def fill(rng):
    """One crate. The opener, the time and the location never come in. Only tables and random numbers"""
    box = collections.Counter()
    for table, tries, chance in SLOTS:
        for _ in range(tries):
            if rng.random() <= chance:
                spawn(table, rng, box)
    box["scrap"] += SCRAP
    return box

Checking common claims

"The contents depend on who opens it"

NoThe contents are already inside when the crate spawns, and opening does not roll. Whoever opens it, the same crate gives the same items.

"Better loot comes out when few people are online"

NoThe roll uses neither the time nor the server population. Population only affects how fast emptied crates respawn.

"A Locked Crate's contents are decided when the hack finishes"

Set at spawnLocked Crates also roll when they appear. The 15 minutes is only the wait until it can be opened.

"What a Barrel drops depends on how you break it"

NoA Barrel's contents are also decided at spawn, and breaking it drops exactly what was inside. Only the extra from Scrap-boosting effects is added when it breaks.

"If you leave a little behind, that crate stays as it is forever"

It refreshesMonument crates do not disappear if something is left, but the 60–120 minute refresh deletes what is left and puts in new contents. For roadside junk pile crates, taking even 1 item makes the whole pile disappear 90 seconds after players leave. How many minutes an emptied crate takes to respawn has not been checked yet.

"A spot where a crate gave good loot will give good loot again"

No linkThe roll uses neither the crate's location nor what came out before. Each time, it simply draws again from the same tables.

"Keep running Military Crates and a Timed Explosive Charge (C4) will turn up eventually"

NeverThe Military Crate tables have no Timed Explosive Charge (C4). To get one from a crate, go for the Bradley Crate (36%), Supply Drop (27%), Heli Crate (26%), Locked Crate (9.6%) or Elite Crate (1.9%).

Unknowns

  • Crates with an infinite refresh time. Elite Crates and Locked Crates have infinity set as their refresh time. The timer is built to "run when the scheduled time arrives", so with infinity it reads as never running. However, what Unity's random function returns when given infinity is inside Unity itself, so we have not checked it.
  • Respawn interval and location. How many minutes an emptied crate takes to respawn, and which crate spawns where, are unknown because we have not read the monument data.
  • Game mode bonuses. The roll weights have a mechanism for adding per-game-mode bonuses. The normal mode has no bonus, and the figures in this article are for that case. The server's era setting is assumed to be the default (no restriction). Modes such as Hardcore and Primitive change the figures.
  • Matching crates to how they look. The match between prefab names and the in-game look and name of each crate is estimated from the prefab names.
  • Scope of this article. It covers the 2026-11-07 version. Table weights change often with updates.
  • Number of Supply Drop draws in 2020. The "8 times" is an old setting left in today's Supply Drop crate (maxDefinitionsToSpawn 8). The code that makes a crate without slots draw this many times still exists, but we have not checked whether the 2020 value was 8.
  • The 2020 code. Old server versions are not available, so for 2020-11 and 2021-08 only the client tables were read, and the calculation assumes that whether an item comes out as a blueprint was set by the same item flag as today (spawnAsBlueprint). The difference from 2021-08 also includes changes from updates other than the Tech Tree Update.
  • Before 2020. Earlier entries in the timeline are based only on the text of the official change notes.

Method

We read the server code, 105 crate settings and 1,327 loot tables (without running the server). The chances were calculated from the tables and checked to match the program's 100,000 crates within 0.5 percentage points (the "at least 1 gun" figures and the Bradley are values from the trials). Tables from old versions were read with scripts/dump_loot_spawns.py. These are not results from opening and counting crates in the game.
